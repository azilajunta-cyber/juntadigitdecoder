💡 Decoding Tips

🎯 Use the Clues First

Sum, even count, first+last total — these eliminate many possibilities.

🔢 Color Code Meaning

🟢 GREEN = correct digit & position. 🟡 YELLOW = digit exists elsewhere. ⚫ GRAY = not in code.

🧠 Elimination Strategy

Gray digits are gone forever. Yellow digits need to move to new spots.

📊 Smart First Guess

Try "1 2 3" or "0 1 2" to quickly discover which digits appear.

⚡ Sum Clue Hack

Small sum = low digits (0-4). Large sum = includes 7-9.
